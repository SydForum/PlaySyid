# 🎵 About AirBeats

**AirBeats** is an advanced, open-source music application built around a modern Material Design 3 experience.

It is designed to provide much more than basic music playback. AirBeats combines:

* 🎵 Music streaming
* 🎨 Deep UI customization
* 🎧 Advanced music playback
* 📝 Advanced lyrics
* 🤖 AI-powered features
* 🧠 Music recognition
* 📊 Personal and global listening statistics
* ☁️ Cloud backup and synchronization
* 🔄 Cross-device synchronization
* 🌐 Multiple music providers
* 💻 Cross-platform desktop integration
* 👥 Listen Together
* 📱 Android system integration
* 🌙 Always-On Display support
* 🏝️ Dynamic Island-style playback experience
* 🌍 Community translations
* 📰 In-app developer news
* 🐛 Automatic crash reporting
* 🌐 A connected AirBeats ecosystem

AirBeats is built to make the entire music experience customizable, connected, and community-driven.

# 🔑 Essential Configuration

> [!IMPORTANT]
> ⚠️ The Firebase configuration file (`google-services.json`) and Google API Key are not included in the repository for security reasons. You must configure these manually to build the project successfully.

## Step 1️⃣ — Firebase Configuration

1. Visit the Firebase Console.
2. Create a new Firebase project or use an existing project.
3. Select **Add Android app**.
4. Register the application with:

```text
Package name:
com.darkxvenom.airbeats
```

5. Set the application nickname to:

```text
AirBeats
```

6. Download:

```text
google-services.json
```

7. Place it inside:

```text
AirBeats/app/google-services.json
```

---

## Step 2️⃣ — Google API Key

Open:

```text
local.properties
```

Add:

```properties
google.api.key=YOUR_GOOGLE_API_KEY_HERE
```

# 🚀 Build Steps

Clone the repository:

```bash
git clone https://github.com/d0x-dev/AirBeats.git
```

Navigate into the project:

```bash
cd AirBeats
```

Clean build files:

```bash
./gradlew clean
```

Build the Debug APK:

```bash
./gradlew assembleDebug
```

The APK will be available at:

```text
app/build/outputs/apk/debug/app-debug.apk
```

---

# 📦 Build Variants

### Release APK

```bash
./gradlew assembleRelease
```

> Requires a properly configured signing key.

### Install on Connected Device

```bash
./gradlew installDebug
```

### Run Tests

```bash
./gradlew test
```
